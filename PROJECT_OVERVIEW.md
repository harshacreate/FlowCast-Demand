# FlowCast-Demand — Hourly Trip-Demand Forecasting

Forecasts hourly trip counts from calendar cycles, weather, event activity, and recent observed demand. The simulator creates a city-scale toy series; it has no specific real city or service as its provenance.

Synthetic hourly data; chronological rolling one-step evaluation. Synthetic seasonal structure is deliberately simplified. Metrics are only for the generated series; a public mobility dataset would require separate provenance and license review before use.
