# FlowCast-Demand — Hourly Trip-Demand Forecasting

**Sector:** Transportation  
**Task:** Hourly trip-count regression

Forecasts hourly trip counts from calendar cycles, weather, event activity, and recent observed demand. The simulator creates a city-scale toy series; it has no specific real city or service as its provenance.

## Data and split

The offline demo is generated by `flowcast/data.py`; it does not download or redistribute external data. Its deterministic simulator creates an hourly series with domain-specific seasonal, weather, trend, event, and lag features. The data are illustrative and do not represent real operators, customers, or environmental conditions.

The holdout is chronological (first 75% for training, final 25% for evaluation). The test is a **rolling one-step** evaluation: each row may use the actual preceding observations to construct its lag features. It does not measure a recursively generated multi-hour forecast.

## Models and evaluation

- **Baseline:** 24-hour seasonal naive forecast (`lag_24`).
- **Stronger model:** histogram gradient-boosting regression trained on the training period only.
- **Metrics:** MAE, RMSE, R², sMAPE, 90th-percentile absolute error, and mean bias. No benchmark is claimed in advance; the CLI prints the measured synthetic holdout results.

## Limitations

Synthetic seasonal structure is deliberately simplified. Metrics are only for the generated series; a public mobility dataset would require separate provenance and license review before use.

## Run

    python3 -m venv .venv
    . .venv/bin/activate
    python -m pip install -e ".[test]"
    python -m flowcast.train --seed 42 --samples 1200
    python -m pytest -q

`make setup`, `make train`, and `make test` are shortcuts. Python 3.9 or newer is required.

## Files

- `flowcast/data.py`: deterministic domain simulator and lagged feature construction.
- `flowcast/split.py`: forward-only holdout.
- `flowcast/model.py`: seasonal-naive comparison, stronger regressor, metrics.
- `flowcast/train.py`: training/evaluation CLI.
- `tests/`: generator, split, metric, and CLI tests.
- `.github/workflows/ci.yml`: test and CLI smoke job.
